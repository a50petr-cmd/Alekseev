## .htaccess и 301 `index.html` → `/`

- В репозитории **файла `.htaccess` нет**.
- На хостинге Рег.ру (Apache) 301 с `/index.html` на `/` обычно **можно** сделать через `.htaccess` или панель, если включён `mod_rewrite`. В прод ничего не менял — только ответ.
