# Черновики статей (inbox)

ИИ кладёт сюда черновик. Вы правите и публикуете через админку на сайте (`/publish/`).  
В прод по FTP **не заливается**.

## Структура одной статьи

```
blog/inbox/{slug}/
  meta.json    — метаданные
  article.md   — текст (абзацы + ## подзаголовки, списки - / 1.)
  cover.jpg    — обложка (jpg/png/webp, необязательно)
```

## meta.json

```json
{
  "slug": "primer-statyi",
  "title": "Заголовок статьи",
  "description": "Короткое описание для dek и meta description (1–2 предложения).",
  "date": "2026-11-10",
  "dateLabel": "10 ноября 2026",
  "category": "Практика",
  "readTime": "5 минут",
  "figure": "3",
  "figureCaption": "шага на старте",
  "imageAlt": "Подпись к обложке"
}
```

Рубрики: `Наставник`, `Франшиза`, `Практика`, `Формат работы`, `Рынок`.

## article.md

Обычный текст. Пустая строка = новый абзац. `##` = H2. Списки: `- пункт` или `1. пункт`.

После публикации статья живёт **вне Git** (на хостинге в `petr-alekseev-data/blog/`) — следующий деплой её не затрёт.
